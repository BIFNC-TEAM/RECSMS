一、主体与适用范围

1.1 本平台全称为“机器人与国产操作系统标准文件协作编辑及版本管理平台”，用于标准文件的归集、共同修订、评审、发布、历史留存与检索。运营方为【待补充：法定全称】，联系地址为【待补充：地址】，服务及申诉联系方式为【待补充：邮箱或电话】。

1.2 本协议适用于本平台网页服务。项目采购合同另有约定的，依法确定其与本协议的适用关系，不以本协议单方减损采购合同或法律赋予用户的权利。平台不因文档被标注为“发布”即对该文档作出国家标准、认证、行政审批或技术合规结论。

二、账号与使用资格

2.1 用户通过本人有权使用的手机号接收验证码完成登录或首次建号；同一手机号对应唯一账号。已有账号可使用原账号或已绑定手机号及原密码登录。手机号校验仅证明当次对号码的控制能力，不等同于法定实名身份认证。

2.2 请妥善保管密码、短信验证码及登录设备，不出借或出售账号。发现异常应及时退出登录并联系运营方。平台应提供合理的身份核验和账号救济，不将所有异常登录风险当然归责于用户。

2.3 本平台主要服务标准编制及相关专业工作。以单位名义操作时，用户应取得相应授权；无相应民事行为能力的用户应依法取得监护或代理授权。平台没有面向儿童设计的服务，不主动要求提供与标准协作无关的身份证、精确定位或通讯录。

三、协作、权限与版本

3.1 每份文档保留一个统一在编稿及历次发布版本。编辑阶段具有权限的用户共同在修订模式下编辑；公开阶段由文档管理者修改，授权评审人员可提交和处理意见；发布须从公开阶段进入，满足保存、批准及阻塞性评审事项关闭条件。发布版本不直接修改，下一轮从最新发布版本建立在编稿。

3.2 未配置额外访问限制的文档，可能向平台其他已登录用户开放查看；编辑取决于平台角色和文档授权。请在上传敏感业务资料前检查目录及文档权限。分享链接不免除登录和权限校验。收藏只保存个人访问入口，不授予阅读或编辑权限，权限撤回后收藏不能继续打开受限文档。

3.3 文档管理者可依法管理成员、阶段截止时间、评审讨论开关和发布。操作须在组织授权范围内，不得冒用其他用户身份、绕过权限、删除必要审计证据或侵犯其他参与者的合法权益。操作记录及修订作者信息可向有权访问该文档的人员展示。

3.4 平台在编辑期间周期性回写保存稿，当前默认约每5秒请求一次持久化；实际完成时间受网络及文档处理影响。“最近保存时间”以平台已接收为准。尚未传出的浏览器改动，在断网、断电或关闭终端时可能丢失。用户可查看保存提示，出现失败时保留编辑窗口并恢复连接；运营方仍应履行合理的数据安全、恢复和故障处置义务。

四、内容与知识产权

4.1 文档、附件、意见等内容的权利归原权利人或依法、依约确定的主体所有。上传不构成向平台转让所有权。用户仅授予运营方为本平台存储、备份、转换、检索及向获授权人员展示内容所必需的处理权限；本协议不授权将非公开文档用于公开传播、商业出售或模型训练。

4.2 用户应确认内容及第三方个人信息的处理具有合法依据，遵守保密、知识产权及项目管理要求。不得上传国家秘密、依法不得在本系统处理的工作秘密、恶意程序、违法信息或明显无权提供的他人资料。发现侵权或错误可向运营方申诉并提供必要证据。

4.3 对违法、侵权或危及安全的行为，运营方可依法采取必要、适度的限制措施，记录理由，在法律允许范围内通知用户并提供申诉渠道；紧急措施解除后应及时复核。不通过不透明规则任意没收合法内容或限制依法应享有的数据访问权。

五、安全与个人信息

5.1 个人信息的处理范围、必要性、服务商、保存和权利行使方式见《隐私政策（预览草案）》。对敏感个人信息、向其他个人信息处理者提供、公开或出境等依法需要单独同意的情形，应另行告知和取得相应同意，不能由本协议一次性概括授权。

5.2 用户可以退出登录并提出查阅、复制、更正、删除、撤回同意和注销请求。组织共同文档的移交、记录留存及第三方权益应分别处理，不能将文档“永久保存”解释为个人信息当然无限期保留。具体受理主体及联系方式须在正式发布前补全。

6.1 平台应采取与风险相适应的访问控制、备份和安全措施，及时处理已知故障。计划维护、重大功能调整或停止服务应在合理期间提前告知；紧急事件应尽快说明影响与恢复安排。当前页面不构成任何付费订购或自动续费授权；如引入收费服务，应另行明示并取得确认。

6.2 因网络、第三方服务或不可抗力造成中断时，双方依法、依约按原因和过错承担责任，平台应采取合理减损、恢复措施，不以第三方原因一概免除自身责任。用户应在权限范围内核对发布内容及导出稿，不应把平台显示的状态代替实质技术审查。

6.3 任何条款不排除运营方依法应承担的人身损害责任，不免除因故意或重大过失造成财产损失的责任，也不限制依法不能限制的个人信息、消费者或其他法定权利。不存在用户对平台的一般性、无上限赔偿承诺；赔偿依适用法律、有效约定及实际责任确定。

七、变更、终止与争议

7.1 重大条款和个人信息处理规则变更应提前显著告知；依法需要重新确认的，应在变更生效前重新征得相应同意，不能仅以继续使用推定同意。用户不同意时可停止使用并依法申请导出、移交或注销。

7.2 注销、停用或运营终止时，应合理安排账号验证、文档责任移交、数据导出及依法删除或匿名化。依法需要留存的部分仅用于规定目的，并限制其他处理；不能以注销为由任意删除其他权利人依法控制的共同文档。

7.3 本协议适用中华人民共和国大陆地区法律。争议可先通过正式公布的客服渠道协商；协商不成，依法向有管辖权的人民法院寻求救济。本协议不以未协商的仲裁或排他管辖条款不当限制用户诉权。
